审计怎么做How the audit works

给定一个模型和一次受控的扰动，审计回答三个问题：实测的响应在模型内部哪一步还读得出来，从哪一步开始读不出来，改了模型以后有没有变好。Given a model and one controlled perturbation, the audit answers three questions: at which internal step the measured response can still be read, where it stops being readable, and whether changing the model made it better.

1

先声明五样东西Five things are declared first

审计前先声明五样东西，连同数据和代码的指纹（sha256）一起封存，再只跑一次。Five things are declared before the audit and sealed together with fingerprints (sha256) of the data and code. The run is then made once.

系统System
冻结的模型，和它实际读入的输入。The frozen model and the input it actually reads.
源Source
受控的扰动，带对照组。A controlled perturbation with a control group.
读出Readout O
独立测量的结果。它不取自模型的输出，也不喂给任何候选状态。An independent measurement, never taken from the model's output and never fed to a candidate state.
候选状态链Candidate states
z₀, z₁, …, zK：系统沿着自己的计算逐步产生的中间量。分析者不在链上加压缩或近似。: intermediates the system produces step by step. The analyst adds no compression or approximation to the chain.
读出模型和判定Readout classes and verdict
用哪几类读出模型（线性的 ridge、树模型 HGB）、容差 ε、置信水平、哪种区间。Which readout classes (linear ridge, tree-based HGB), the margin ε, the confidence level and the interval type.
2

检验量和判定The statistic and the verdict

对每一环 z，用声明的读出模型（线性的 ridge 和树模型 HGB，按靶点交叉拟合）拟合读出和处理，再看扣掉这一环知道的一切之后，处理还能解释读出多少：θ(z) = E[(O − m(z))(A − e(z))] / E[(A − e(z))²]，u = θ(z) / Δ。u 是读不出的那部分占实测响应 Δ 的比例：0 是全读得出，1 是一点读不出。For each stage z, the declared readout models (linear ridge and tree-based HGB, cross-fitted by target) fit the readout and the treatment; what counts is how much of the readout the treatment still explains once everything the stage knows has been used: θ(z) = E[(O − m(z))(A − e(z))] / E[(A − e(z))²], u = θ(z) / Δ. u is the unreadable part as a share of the measured response Δ: 0 means all of it is readable, 1 none.

沿链把判定连起来，工具给出一个根因（按顺序取第一个成立的）：Reading the verdicts along the chain, the tool prints one root cause (the first that applies, in this order):

根因Root cause含义Meaning
no_effect读出没有可解释的响应the readout has no response to explain
control_failed阳性对照没读出来，这次检验本身不可信the positive control is not recovered, so the test itself is not trusted
loss_at参照环得到支持，后面某一环被否定：丢失在两者之间the reference stage is supported and a later one is rejected: the loss lies between them
relative_loss_at参照环没在容差内，但有一步明确多丢了the reference stage is not within tolerance, but one step adds a resolved loss
reference_unresolved参照环没定清，也没有哪一步明确多丢the reference stage is unresolved and no step adds a resolved loss
unresolved区间跨过容差，下不了结论the intervals cross the margin; no conclusion
no_deficit每一环都在容差内every stage is within the margin

4

类型化的源事件：事件图怎么建Typed source events: how the event graph is built

一次运行的源不是一个标签，而是一组事件。每个事件写明：什么时候、打在哪个位点（哪个基因）、走哪个通道、方向和幅度，再加上角色、层、来源、合并方式和准入。python -m anm_diag events 只读声明和已有的记录，不碰细胞数据，写出事件并报告三件事。The source of a run is not one label but a set of events. Each event states when, at which site (which gene), through which channel, with what sign and amplitude, plus its role, stratum, provenance, pooling and admission. python -m anm_diag events reads declarations and finished records only, touches no cell data, writes the events and reports three things.

  • 合并丢了哪些字段（规则 S2）。把几个靶基因、几个批次并成一个处理组，等于丢掉“位点”或“层”这个字段。合并的判定不等于每个被合并的值的判定，所以合并要声明，否则给出警告。Which fields a pooled source drops (rule S2). Merging several target genes or batches into one treated arm drops the field “site” or “stratum”. A verdict for the pool is not a verdict for each pooled value, so pooling must be declared or a warning is raised.
  • 防泄漏（规则 S3、S4、R2）。每个事件带三条检查：细胞是怎么选出来的（按向导或设计，不能按实测的响应）；读出的测量是不是也进了系统的输入；事件打的是不是读出自己的基因。No leakage (rules S3, S4, R2). Each event carries three checks: how its cells were chosen (by guide or design, never by the measured response); whether the readout's measurement is also a system input; whether the event acts on the readout's own gene.
  • 判定台账。每个判定也写成事件，再列出不同运行之间相反的判定，以及它们在哪个字段上不同。The verdict ledger. Every verdict is written as an event too, and opposite verdicts between runs are listed with the field in which the runs differ.

用在封存的两次运行上：合并的源被标出来，于是对每个靶基因、每个批次单独重审（runs/split_20261111）。PD-L1 的定位对每个靶基因都成立；15 次运行的 155 条判定里没有一对相反；两套数据的 25 个真实敲除事件都通过了三条防泄漏检查。Applied to the two sealed runs: the pooled source is flagged, so the audit was repeated for each target gene and each batch alone (runs/split_20261111). The PD-L1 location holds for every target gene; the 155 verdicts of 15 runs contain no opposite pair; all 25 real knockout events of the two data sets pass the three leakage checks.

闭环The loop

定位是观察，闭环是检验这个观察：照定位去改系统，再用同一个审计量一遍。A location is an observation; the loop tests it: change the system where the location points and measure again with the same audit.

闭环其实是两个，问的问题不同，要的证据也不同。There are two loops. They ask different questions and need different evidence.

诊断闭环Diagnostic loop修复闭环Repair loop
问题Question定位到的那一步，是不是这个响应的要害Is the located step the one that matters for this response改过的系统还丢不丢，原来的任务还在不在Is the changed system free of the loss, and still good at its own task
比什么What is compared同一个基线上的两种改法：一种改在定位到的那一步，一种改在别处two changes against one baseline: one at the located step, one elsewhere改过的系统，对只差这一处改动的对照the changed system against a control that differs only by the change
量什么Quantity基线多丢的部分，被每种改法去掉的比例，和两者之差，都带区间the share of the baseline's loss each change removes, and the difference, each with an interval改过的系统还多丢多少（带区间），和末端那一环的判定what the changed system still adds, with its interval, and the verdict of the end stage
结论的性质Kind of claim一种改法比另一种去掉得多one change removes more than the other丢失不在了the loss is absent
需要什么What it needs基线的丢失相对它的区间够大a baseline loss that is large against its interval区间相对容差够窄；没被任何设计决定用过的数据intervals narrow against the margin; data no design decision has seen

诊断闭环过了，只说明该在哪里动手，不说明系统修好了。每一步花钱之前先过一道便宜的关：准入、定位、开方子、修复准入、开发审计、终审、用途。准入这一关在动手之前就回答“这批数据能不能认出一个修好的系统”。读法由 python -m anm_diag loop admit | diagnose | closure 从已有的运行记录里算，不做新的拟合。Passing the diagnostic loop says where to work. It does not say the system is repaired. A cheap gate stands before every step that costs something: admission, location, prescription, admission of the change, development audit, final audit, use. Admission answers, before anything is changed, whether these data could recognize a repaired system at all. The readings are made by python -m anm_diag loop admit | diagnose | closure from the records of finished runs, with no new fit. 闭环协议全文The loop protocol in full

证据等级Evidence grades

  • 封存、只跑一次：确认性。声明连同数据和代码的哈希先封存；封存后改过设计、数据或代码，运行会被拒绝。Sealed and run once: confirmatory. The declaration is sealed with hashes of data and code; a run is refused if design, data or code changed after sealing.
  • 设计先提交，但在看过别的结果之后才定：探索性。闭环的各轮属于这一类，提交历史能看出先后。Design committed first, but fixed after other results were seen: exploratory. The rounds of the loop are of this kind; the commit history shows the order.
  • 事后重读：探索性，原来的判定不变。Post hoc rereading: exploratory, and the original verdicts stand.
形式定义（10 条）Formal definitions (10 items)
  1. 响应。Δ = E[O | A = 1] − E[O | A = 0]。它的区间不含 0 才继续；否则没有响应可查。Response. Δ = E[O | A = 1] − E[O | A = 0]. The audit continues only if its interval excludes 0; otherwise there is no response to examine.
  2. 充分性。状态 z 对读出充分，是指给定状态以后，读出的均值不再依赖有没有扰动：E[O | z, A] = E[O | z]。论文写作 O = Ō ∘ G。Sufficiency. A state z is sufficient for the readout when, given the state, the mean readout no longer depends on the perturbation: E[O | z, A] = E[O | z]. The paper writes O = Ō ∘ G.
  3. 到达。先看扰动有没有到达这一环：只凭这一环的状态，能不能把处理和对照分开（AUC）。没有到达的环谈不上保留。Arrival. First check that the perturbation reaches the stage: can the state alone separate treated from control (AUC)? A stage it never reached cannot retain anything.
  4. 检验量。θ(z) = E[(O − m(z))(A − e(z))] / E[(A − e(z))²]，u(z) = θ(z) / Δ。m 和 e 是声明的读出模型，交叉拟合。u 是同状态下还剩的差别占 Δ 的比例，按重叠加权平均。Statistic. θ(z) = E[(O − m(z))(A − e(z))] / E[(A − e(z))²], u(z) = θ(z) / Δ. m and e are the declared readout models, cross-fitted. u is the share of Δ that remains at equal state, an overlap-weighted average.
  5. 判定。某一类读出模型的整个区间落在 (−ε, ε) 里，是支持；每一类都整个落在外面，是否定；其余是未决。Verdict. One readout class with its whole interval inside (−ε, ε): support. Every class wholly outside: reject. Otherwise: unresolved.
  6. 定位。参照环（输入视图）先要得到支持。沿链找到第一个被否定的环，丢失就在它和最后一个得到支持的环之间。Localisation. The reference stage (the input view) must be supported first. Find the first rejected stage along the chain; the loss lies between it and the last supported stage.
  7. 这个丢失说明什么。看这段路上每一步的映射。全是可逆映射，信息就还在，被否定的只是读出模型（论文表 2 第 3 行）。有不可逆的步骤，表示本身才可能丢了信息。What the loss means. Look at each map on that stretch. If all are invertible, the information is still there and only the readout class is rejected (paper Table 2, row 3). Only a non-invertible step can have lost information in the representation itself.
  8. 对照。把读出自己当状态，u 应为 0。把某个状态的行打乱，它必须被否定，否则“支持”不算数。每个状态报告有效细胞数。Controls. Using the readout itself as the state must give u = 0. A state with shuffled rows must be rejected, or “support” means nothing. Each state reports its effective number of cells.
  9. 闭环。改了系统、带着对照再测以后，原来被否定的环得到支持，而对照组没有，才能说这次改动消除了丢失。两处一起变只说明干预下有关联，不说明谁经过谁；要分清是传播变了还是读出变了，得有状态的测量或者有选择的干预（SI S1.3）。Closing the loop. A change removed the loss only if, after changing the system and measuring again with a control arm, the rejected stage becomes supported and the control arm's does not. Two things moving together show association under intervention, not which passes through which; telling a change in propagation from a change in readout needs state measurements or selective interventions (SI S1.3).
  10. 证据等级。先封存、再只跑一次的结果是确认性的。看过结果之后才定的方法，只算探索性证据，原来的判定不变（论文第 8 页）。Evidence grade. Sealed first and run once: confirmatory. A method fixed after seeing results gives exploratory evidence, and the original verdict stands (paper, p. 8).
