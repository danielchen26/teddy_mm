Mode B · must-separate pairs · site4/test

TEDDY sees two cells as the same. They aren’t. Here’s how ANM catches it.

Frozen TEDDY z_512 puts myeloid and T cells at cosine 0.982. A readout built on it falsely agrees 85% of the time. ANM’s decision loop vetoes z_512 as sufficient, complements it with typed true-ADT evidence and an editable observer (O1), and verifies on the same pairs. No TEDDY retrain.

The loop, one step at a time

Click a step or use ← / → keys. Every number below is copied from the run’s stats files.

1 · What TEDDY alone is expected to give you

A frozen RNA→protein map. Downstream readout treats cells with nearby z as the same biology.

RNA→ frozen TEDDY-G→ z_512→ ADT preds→ panel rules (O0)→ call

What z_512 is

Mean-pool of last-layer tokens at context 1024, L2-normalized, full 512-D (z_rna_512.npy, site4/test n = 16,750). Not pretrain 2048, not the disease token, not compact z_keep=32.

The implicit promise

If cos(zi, zj) ≥ 0.98, the readout gives both cells the same call. Phase-1 full-ADT Pearson reference ≈ 0.61 — this page does not try to beat it.
The question: is z_512 sufficient for the readout? The cheapest probe that tests it — the must-separate autopsy — was the strongest of four cheap probes (primary metric 0.581, rank 1 in CHEAP_PROBES_RANKING).

What ANM uniquely adds — vs just swapping features

If true ADT is the fix, why not concatenate it into the embedding? Because geometry that separates a fixed list is not a readout that owns its decisions.

Claim boundary

“Reverse loop” here is a decision loop. It is not a representation-response loop.

Claimed (Mode B)

  • Veto → complement → verify on must-separate pairs
  • z_512 alone is insufficient for readout on these pairs
  • True ADT as typed complement evidence — explicit probe only
  • Editable observer declaration (O1) without TEDDY retrain
  • Production path keeps holdout ADT verifier-only

Not claimed

  • Mode A: residual stream as field, layer Jacobian, in-silico gene perturbs
  • Reverse closed loop as representation response to perturbs
  • Pearson > phase-1 full-ADT ~0.61
  • Fusion audit · clinical superiority
  • TEDDY best.pt retrain
On reverse_step1 must-separate pairs (5,000 written; 1,490 myeloid↔T with median cos 0.982), TEDDY z_512 alone is insufficient for readout (baseline false_agree 0.85, soft_sep 0.17, Q 0.74). The Mode B ANM decision loop vetoes sufficiency, admits true-ADT typed evidence + editable O1 observer as complement, and verifies false_agree → 0.40, soft_sep → 0.63, Q → 0.99 — without TEDDY retrain. Swapping features into z⁺ is not enough (global relative_must_reduction −0.27). Not Mode A. Not Pearson > ~0.61. Not clinical.
