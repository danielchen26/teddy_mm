• 响应。Δ = E[O | A = 1] − E[O | A = 0]。它的区间不含 0 才继续；否则没有响应可查。Response. Δ = E[O | A = 1] − E[O | A = 0]. The audit continues only if its interval excludes 0; otherwise there is no response to examine.
  • 充分性。状态 z 对读出充分，是指给定状态以后，读出的均值不再依赖有没有扰动：E[O | z, A] = E[O | z]。论文写作 O = Ō ∘ G。Sufficiency. A state z is sufficient for the readout when, given the state, the mean readout no longer depends on the perturbation: E[O | z, A] = E[O | z]. The paper writes O = Ō ∘ G.
  • 到达。先看扰动有没有到达这一环：只凭这一环的状态，能不能把处理和对照分开（AUC）。没有到达的环谈不上保留。Arrival. First check that the perturbation reaches the stage: can the state alone separate treated from control (AUC)? A stage it never reached cannot retain anything.
  • 检验量。θ(z) = E[(O − m(z))(A − e(z))] / E[(A − e(z))²]，u(z) = θ(z) / Δ。m 和 e 是声明的读出模型，交叉拟合。u 是同状态下还剩的差别占 Δ 的比例，按重叠加权平均。Statistic. θ(z) = E[(O − m(z))(A − e(z))] / E[(A − e(z))²], u(z) = θ(z) / Δ. m and e are the declared readout models, cross-fitted. u is the share of Δ that remains at equal state, an overlap-weighted average.
  • 判定。某一类读出模型的整个区间落在 (−ε, ε) 里，是支持；每一类都整个落在外面，是否定；其余是未决。Verdict. One readout class with its whole interval inside (−ε, ε): support. Every class wholly outside: reject. Otherwise: unresolved.
  • 定位。参照环（输入视图）先要得到支持。沿链找到第一个被否定的环，丢失就在它和最后一个得到支持的环之间。Localisation. The reference stage (the input view) must be supported first. Find the first rejected stage along the chain; the loss lies between it and the last supported stage.
  • 这个丢失说明什么。看这段路上每一步的映射。全是可逆映射，信息就还在，被否定的只是读出模型（论文表 2 第 3 行）。有不可逆的步骤，表示本身才可能丢了信息。What the loss means. Look at each map on that stretch. If all are invertible, the information is still there and only the readout class is rejected (paper Table 2, row 3). Only a non-invertible step can have lost information in the representation itself.
  • 对照。把读出自己当状态，u 应为 0。把某个状态的行打乱，它必须被否定，否则“支持”不算数。每个状态报告有效细胞数。Controls. Using the readout itself as the state must give u = 0. A state with shuffled rows must be rejected, or “support” means nothing. Each state reports its effective number of cells.
  • 闭环。改了系统、带着对照再测以后，原来被否定的环得到支持，而对照组没有，才能说这次改动消除了丢失。两处一起变只说明干预下有关联，不说明谁经过谁；要分清是传播变了还是读出变了，得有状态的测量或者有选择的干预（SI S1.3）。Closing the loop. A change removed the loss only if, after changing the system and measuring again with a control arm, the rejected stage becomes supported and the control arm's does not. Two things moving together show association under intervention, not which passes through which; telling a change in propagation from a change in readout needs state measurements or selective interventions (SI S1.3).
  • 证据等级。先封存、再只跑一次的结果是确认性的。看过结果之后才定的方法，只算探索性证据，原来的判定不变（论文第 8 页）。Evidence grade. Sealed first and run once: confirmatory. A method fixed after seeing results gives exploratory evidence, and the original verdict stands (paper, p. 8).
