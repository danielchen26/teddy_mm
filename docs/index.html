CITE-seq · NeurIPS 2021 BMMC · holdout site4/test · n = 16,750

Keep TEDDY frozen.
Make its answers editable, honest and auditable with ANM.

TEDDY maps a cell’s RNA to its surface proteins (phase-1 full-ADT Pearson ≈ 0.61). On its own it can’t change the question without new labels, stay silent when evidence is weak, explain a call, show where it can be trusted, or notice when two different cells look identical to it. We put ANM on top of TEDDY’s unchanged predictions and test each of these head-to-head.

01 — The problem

TEDDY gives good evidence. Deciding from it is the gap.

A frozen RNA→protein map answers one fixed question, the same way, for every cell. Six things a biologist needs from a readout are missing. Each one became a block, with its own test.

GAP 1

Change the question

Can I switch to a stricter or marker-priority criterion?

TEDDY aloneRules are hard-wired. A new criterion means re-tuning on labels; until then it keeps answering the old question — on 1,752 cells that O2 would hold back.

Block 1 · Edit the question → GAP 2

Weak or missing input

What if only ADT was measured?

TEDDY aloneAnswers every cell anyway: 0 abstentions at Q 0.63 under adt_only.

Block 2 · Missing modality → GAP 3

Explain a call

Which marker drove this call, and how close was it to flipping?

TEDDY aloneNo declared decision field, so no per-marker leave-one-out and no flip distance.

Block 3 · Attribution → GAP 4

Know where to trust it

Which calls are safe to act on, and which need follow-up?

TEDDY aloneNo graded signal to gate on. Every call looks equally certain.

Block 4 · Scope gate → GAP 5

Price of a new criterion

What does adopting O2 cost with a trained readout?

Trained readout50–500 new endpoint labels per switch, just to match the numbers — and again at the next change.

Block 5 · Zero-label transfer → GAP 6

Is the embedding enough?

Can TEDDY tell when two different cells look the same to it?

TEDDY aloneSome myeloid and T cells sit at cosine 0.982 in z_512; the readout falsely agrees on 85% of those pairs.

Block 6 · Decision loop →

Not a goal: beating TEDDY’s Pearson ≈ 0.61 or retraining it. TEDDY’s predictions are the input to every block, unchanged.

02 — How we compare

One fair test, reused in every block

Every block runs the same arms on the same frozen predictions. “ANM helps TEDDY” means TEDDY + ANM beats TEDDY alone on a decision property with TEDDY unchanged, and a trained head can’t get there without buying labels.

Four rules

R1
Same frozen TEDDYbest.pt is never retrained. Every arm reads the same predicted 9-protein panel (δu).
R2
Same cellsHoldout site4/test, n = 16,750. Out-of-site check on val_non_site4, n = 2,000.
R3
Truth only verifiesHoldout true ADT sets the expected answer and never enters ANM’s evidence. One labelled exception: Block 6’s complement probe.
R4
Decision metrics firstAbstention, label cost, attribution, coverage vs Q, false agreement. Accuracy is reported, never the win condition.

Three arms

Baseline

TEDDY alone

Predicted panel → lineage score → argmax with a threshold (the O0 rule). What TEDDY gives out of the box.

Treatment

TEDDY + ANM

The same predictions as typed evidence events → ANM finite_field under a declared observer (O0 / O1 / O2) → call or abstain, with Pf and Qf.

Control

Train + Jev

A head trained on labels over the same frozen features: log-loss logistic, MLP or threshold grid. A Jev-class stand-in, not the live Jev API. Asks: “could any trained head do this?”

help = (TEDDY + ANM) − (TEDDY alone) on identical δu,  with Train + Jev as the “just train harder” control

So a block only counts if the difference comes from the decision layer. TEDDY’s evidence is the same number in every arm.

δu · typed evidence
TEDDY’s predicted value for each of the 9 panel proteins, exported as a typed source event.

        
Observer O0 / O1 / O2
The decision criterion: thresholds, marker weights, what counts as a confident call. Declared in CRITERIA (bridge_anm/lib/lineage_panels.py), mirrored as YAML in bridge_anm/readouts/.

        
Pf · workability
1 if the declared observer can call from the evidence, else abstain. Mean Pf = share of cells called.

        
Q · among decided
Share of calls that match holdout true ADT. Holdout truth is used only here, as a verifier.

        
soft_P
max(action_scores) of the declared field: the continuous signal under binary Pf, used to gate.

        
LOO · flip distance
Remove one protein event and re-decide. Flip distance = smallest change to that event that flips the call.

        
Must-separate pair
Two cells with near-identical z_512 (cos ≥ 0.98) whose true ADT lineage or profile disagrees.

Block 3 · leave-one-out on the declared field
Attribution
For any call, which marker carried it, and how far was it from flipping?

          HARD_PROOF ↗
        

        

          

            
Problem · TEDDY alone
A TEDDY-alone call is an argmax over panel scores. With no declared decision field there is no principled way to ask which marker carried the call or how close it came to flipping. A trained head only offers learned coefficients.

            
Compared

              TEDDY + ANM (O0 field)all decided cells · n = 16,433
              bootstrap B = 200permutation n = 100

            
Workflow
    
              
  1. Decide. Run the declared O0 field for every cell.
    2. 
              
  2. Leave one out. Drop each typed protein event in turn and re-run the field.
    3. 
              
  3. Rank. Top protein by |Δ chosen score|; record whether the call flips.
    4. 
              
  4. Flip distance. Grid-search the smallest change to that event’s value that flips the call.
    5. 
              
  5. Test. Bootstrap the top-1 distribution (B = 200); permutation test against a shuffled null (n = 100).
    6. 
            
bridge_anm/run_hard_proof.py --attr-n 0 --n-boot 200 --n-perm 100

Block 4 · soft_P gate + attributed scope
Scope gate
Can we tell which of TEDDY’s calls to act on, and which cells are genuinely hard?

          SCOPE_REFINE ↗
        

        

          

            
Problem · TEDDY alone
Every TEDDY-alone call looks equally certain. Without a graded signal you can’t choose which cells to act on, or where to spend a small follow-up or labelling budget.

            
Compared

              TEDDY alone (answers all)TEDDY calls × ANM soft_P gate
              random same-n controlsite4/test n = 16,750

            
Workflow
    
              
  1. Score. soft_P = max(action_scores) from the declared field.
    2. 
              
  2. Gate. Sweep τ; keep TEDDY’s own call only where soft_P ≥ τ; record coverage and Q against holdout truth.
    3. 
              
  3. Scope. ANM hard cells = LOO flip-sensitive (n = 4,557). Compare their Q with 40 random draws of the same size.
    4. 
              
  4. Budget. Train a small head on frozen TEDDY features with labels from ANM-hard vs random cells; evaluate on the hard holdout.
    5.

04 — Claim boundary

      
What we claim, and what we don’t

      
This is Mode B: TEDDY as a typed evidence source for ANM decisions. Nothing here reads TEDDY’s internals.

      

        
Claimed · Mode B
    
          
  • TEDDY typed evidence → ANM finite_field decisions
    • 
          
  • Editable observer declarations (O0 → O1 → O2), no TEDDY retrain
    • 
          
  • Missing-modality abstention; LOO / flip attribution on decisions
    • 
          
  • Scope gate and zero-label observer transfer vs Train + Jev
    • 
          
  • Decision loop: z_512 alone is insufficient on must-separate pairs → veto → complement → verify
    • 
        

        
Not claimed
    
          
  • Mode A: residual stream as field, layer Jacobian, in-silico gene perturbs
    • 
          
  • Reverse loop as representation response to perturbs · gated ±ε G1–G4
    • 
          
  • Pearson > phase-1 full-ADT ≈ 0.61
    • 
          
  • Fusion audit · ATAC / chromatin · clinical superiority
    • 
          
  • Live Jev API (Train + Jev is a log-loss stand-in)
    • 
        

      

      

        
Honest weak spots

        
    
          
  • ADT-only is a weak channel (panel Pearson 0.446). The Block 2 story is honest silence, not a better model.
    • 
          
  • Accuracy is roughly tied in Block 1. HARD_PROOF’s three-arm table lists ANM’s mean Qf, which counts abstentions as misses (0.939 / 0.958 / 0.821). This page compares Q among decided cells for both arms.
    • 
          
  • Block 4 trades coverage for Q; O2 dips at very low coverage; label-budget gains are small and mixed.
    • 
          
  • Block 6 uses true ADT as an explicit complement probe. Production keeps holdout ADT verifier-only.
    • 
        

      

      
z_512 = mean-pool of last-layer tokens at context 1024 (not pretrain 2048, not a disease token), L2-normalized 512-D (z_rna_512.npy). The compact z_rna_export.npy (z_keep=32) is not the probe space. Full scope: MODE_B_SCOPE.md.
